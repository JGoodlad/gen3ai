counterfactual — what if it had played something else?

Everything above is a reading of the decision as it happened. These three re-play it. They run in the background (submit, then this box polls), they need the shared password, and they only work on a bridge-eval trace — the one with a *_reconstruction.json sibling.

lookahead — one ply

Re-roll this turn under every legal action (the opponent plays its recorded move, the dice held fixed) and read the critic's V(s′) for each. Answers “was there a better move this turn, by the critic's own reckoning?”. ≈2 s at 0 extra seeds; each extra seed re-rolls the whole sweep again.

better line — search

The depth-≥2 generalization: a CRN-anchored beam over the critic that clones mid-battle states, returning one contrastive trajectory (“at turn T do X instead”). ≈2 s at depth 1, ≈4 s at depth 2, ≈5 s at depth 3. A confirm rollout is a whole game on top — seconds each.

replay to a win/loss

Substitute one action here and play the rest of the game live against the reloaded opponent: “could it have won if it hadn't choked this turn?”. Each rollout is a full game — seconds. One rollout is a single realized-dice line and not a probability.

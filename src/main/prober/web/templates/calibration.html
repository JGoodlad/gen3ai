Critic calibration — calibration

Splits falsify_scan's unattributed bucket into critic_overvalued (epistemic — a better critic helps) and lost_position (the critic was right), by comparing recorded V(s) to the realized discounted return G(s) against a reliability curve fit over both wins and losses. Binning by V rather than by outcome is what keeps the baseline selection-free — a loss-conditioned V−G is biased positive by construction.

It still self-diagnoses a confound it cannot remove: the captured sample's win fraction is set by the eval capture quota, not the true win rate, so the headline number is a loose upper bound. The bias_on_wins / bias_on_losses split below is the calibrated-critic signature — read it before the headline.

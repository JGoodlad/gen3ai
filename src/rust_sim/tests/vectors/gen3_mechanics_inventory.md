GENERATED by `harness/dump_gen3_mechanics.js` from the RESOLVED `Dex.mod('gen3')`
(the whole mod chain applied — never raw data files; see the mod-chain law).
Regenerate: `node src/rust_sim/harness/dump_gen3_mechanics.js`.
Drift gate: `node src/rust_sim/harness/dump_gen3_mechanics.js --check` (verifies the
committed `data/pokemon/gen3_items.json` / `gen3_abilities.json` mechanics fields
against the resolved dist — run it whenever either regenerates).

Universe: every item with `num>0 && gen<=3` in the resolved gen3 dex, PLUS the 4
gen4-named incenses the sim still applies under gen3 formats (odd/rock/rose/wave —
documented exceptions, present in MODELED_ITEMS); every ability num 1..76.

Legend: **modeled** = the port prices it today (engine, via the data-driven path or a
dedicated mechanic); *noop-admitted* = provably no-op in the e2e's modeled-move fuzz
(NOOP_ABILITIES); unmodeled = not yet priced (its class is a future phase). DRAW =
draw-bearing (rolls the PRNG when it fires -> its class needs a draw-order probe
before wiring); draw-free otherwise.

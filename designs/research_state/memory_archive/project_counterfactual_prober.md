2026-06-21 (worktree bridge-cse, base dd5a3ed/v32, NOT shipped — awaiting /gen3ai-ship). Built the two prober features the user asked for ("see how V changes with lookahead" + "could it have won if it hadn't choked one turn"; MCTS deferred per [[project_l3_oracle_grind_l4]] + perf). Both are RE-ROLL powered → bridge-eval traces with `*_reconstruction.json` only.

**Feature 1 — one-ply lookahead / value-delta** (`src/main/prober/lookahead.py` + `ProbeModel.value_dist_at`/`win_prob_at`): per legal action, `reroll_turn` one turn (opp plays RECORDED move), materialize the one-sided successor obs, read `model.value` → per-action V(s′)/ΔV. CRN headline (`"original"` seed = hold realized dice, vary only our action) + optional dice-average (`n_seeds>0`). The CHOSEN action's CRN successor reproduces the real next state, so `value_crn == recorded_next_value` — a built-in faithfulness anchor (VERIFIED in production: 18.6521==18.6521 on ai_v6_03). Session: `lookahead`; CLI: `query lookahead`.

**Feature 2 — counterfactual replay-to-end** (`src/utils/bridge/counterfactual.py` + `src/main/prober/replay.py`): substitute a move at turn T, play the rest LIVE (trainee policy vs RELOADED real opponent) to a win/loss. Reuses `run_local_battles` with both players' `choose_move` SCRIPTED to replay recorded commands until divergence, then live. **The user's key correction** (over my first synthesis): reload the REAL opponent, don't self-play-approximate — bots rebuilt exactly, `--opponent-ckpt` for a sentinel, self-model only as a flagged fallback. Monte-Carlo via `local_sim_bridge.js` `resumeReseed` (PRNG swap at the divergence turn START → prefix keeps recorded dice, continuation resamples) → win-rate ± Wilson CI. Session: `replay_counterfactual`; CLI: `query replay-counterfactual <id> <inv> <action> --rollouts N`. TUI: `L`/`C` in a new Counterfactual section (`app.py`).

**THE faithfulness design** (the hard part): the scripted prefix must keep the post-divergence turn-history obs faithful, so each scripted Gen3Player decision runs `embed_battle` + `tracker.advance(recorded_idx)` — recorded index recovered by INVERTING the recorded choice string via the action mapper (`_invert_choice`, the `map_actions_at` inverse). PROVEN bit-for-bit by `counterfactual_fuzz_test.py`: full scripted replay reproduces the recorded WINNER **and** the recorded npz obs bit-for-bit (obs_roundtrip guarantee carried through the live path) + reseed keeps prefix fixed + deterministic per seed.

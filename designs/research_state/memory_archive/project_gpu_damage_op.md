2026-06-14 (design + PROOF, NOT built into the model). Idea: compute damage as **differentiable "physics" on the GPU, fed by the belief's soft distributions**, instead of (a) the CPU obs-build calc (can't see the GPU belief same-decision — cross-proc) or (b) trusting the trunk to learn it (FALSIFIED: trunk recovers outgoing damage WORSE than raw obs, see [[project_belief_latent_role_probe]]). Principle: **learn the epistemic (belief over identity), COMPUTE the deterministic (damage/effectiveness — known functions belong as fixed/differentiable ops, not learned), represent the aleatoric (rolls/crits) as distributions.** GPU is 86% idle, CPU obs-build is the bottleneck → moving the calc to GPU uses the free resource.

**PROOF (ran, both tests pass; code in worktree agent-a745d31723e3c41c2/src/main/gen3_damage_calc_torch.py + _test.py):**
- **Byte-for-byte equivalence:** torch float64 == numpy oracle (src/main/gen3_damage_calc.py) on 600 real OU triples → max abs/rel diff **0.0, 600/600 exact**; all 5 type-immunity cases exactly 0.0 both sides. float32-CPU drift ~2e-7 (irrelevant on [0,1]). On-GPU number NOT measured (training owns the card, 252MiB free — correctly did NOT touch it; device-agnostic kernel → same float32 class; runs on GPU in prod forward anyway). ⇒ "can we do this" = PROVEN YES.
- **Differentiable through the belief:** soft dist over 8 candidate defenders → finite nonzero grad (L2 0.10 logits). Can train through it into the belief head.
- **THE KEY FINDING — Jensen gap:** damage-of-AVERAGE-inputs (mean-field, blend-then-compute) = 0.894 vs E[damage] (marginalize, Σ P(s)·dmg(s), simulate-then-average) = 0.615 → **0.28 systematic OVERESTIMATE**. Damage is nonlinear (1/Def, multiplicative type product, bimodal immunity) so blending inputs first LIES. ⇒ production op MUST MARGINALIZE (enumerate candidates, compute each exactly, weight) — which is exactly the user's "simulate the moves we haven't seen" intuition; it's not just powerful, it's the Jensen-UNBIASED method. Bimodal "could be Levitate → 0" stays honest instead of smearing to 0.8×.

**HYBRID belief representation (user design, validated):** MONS = soft species DISTRIBUTION (op contracts → expected stats/types; "continuous" role richness from embedding geometry for the policy). MOVES = discrete multi-label ids (op looks up EXACT BP/type/category — same-type moves differ sharply: Giga Drain 60+drain vs HP Grass 70; blur-intolerant). Discrete moves SUBSUME the move-role concern (offense/support derived from looked-up flags) AND recover graded similarity via the op's marginalization (Fire Blast≈Flamethrower priced alike). HIDDEN POWER needs a type/BP rider (one id, type from IVs — gen3_hidden_power_priors.json + tracker exist). General principle: continuous vs discrete by BLUR-TOLERANCE (smooth-in-similarity → continuous; sharp-per-identity → discrete).
